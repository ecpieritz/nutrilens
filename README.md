# NutriLens

NutriLens is a food-intelligence web application for discovering, examining,
comparing, and organizing packaged-food records.

## Requirements

- Node.js 24.18.1
- npm 10.8.2 or newer

Use the Node.js version declared in `.nvmrc` before installing dependencies.

## Setup

```sh
npm install
```

## Project status

The repository workspace and runtime tooling are initialized. The Open Cells
application bootstrap is intentionally reserved for the next implementation
step in the semantic commit roadmap.
